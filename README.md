# Субподряд — корпоративный сайт

Одностраничный сайт проекта «Субподряд»: подбор и сопровождение рабочих и бригад для строительных и промышленных объектов.

## Стек
- HTML
- CSS
- Vanilla JavaScript

## Локальный запуск
Откройте `index.html` в браузере или запустите любой статический HTTP-сервер.

## Важно
Контактный блок намеренно не содержит выдуманных телефона, Telegram или email. После подтверждения рабочих контактов их можно добавить в секцию `#contact`.
